# Philippine Stock Exchange - Admin App

This repository contains the **Admin application** for the Philippine Stock Exchange (PSE) system. The Android app is designed for administrators and support staff to manage listings, monitor trades and oversee user activity within the PSE platform.

## Features

- **Administrative dashboard**: Provides insights into market activity, pending approvals and system health.
- **Listings management**: Add, update or delist company securities and ensure compliance with exchange rules.
- **Trade oversight**: Monitor order books, review large trades and intervene in suspicious activity.
- **User management**: Approve new user accounts, assign roles and manage permissions.
- **Notifications & alerts**: Receive alerts about unusual trading patterns, regulatory notifications and system events.
- **Secure authentication**: Restricted access for authorized administrators only.

## Getting Started

1. Clone this repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync and download dependencies.
4. Configure environment settings, API endpoints and admin credentials in the appropriate configuration files.
5. Build and run the app on an Android device or emulator with admin access.

## Technologies

- Kotlin & Java for Android
- Android Jetpack libraries (LiveData, ViewModel, Navigation)
- RESTful APIs & WebSockets for market data
- Gradle build system
